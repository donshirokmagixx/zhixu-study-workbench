# 北邮本科期中/期末命题风格

本 Skill 依据 10 套公开校内试卷的结构分析校准命题风格，不提供原题、不复制原题、不把样卷当作课程知识证据。资料边界仍由 grounded-quiz-generator 决定，教师命题质量由 experienced-teacher-examiner 负责。

## 一、整卷骨架

1. 用户选择的题型和数量是硬约束。本 Skill 只决定这些题如何呈现，不擅自增加题型或题量。
2. 默认 100 分制思维组织，但产品当前不输出分值；不要虚构“共 X 分”或给题目编造分数。
3. 整卷控制在 5–9 个自然分组。用户没有要求分节时，仍要让题型和难度有清楚顺序：基础客观题在前，综合计算/分析题在后。
4. 常规难度配比：基础 25%、中等 55%、综合 20%。若用户题量以基础题为主，可调整为 35/50/15；不得让综合题超过总题量三分之一。
5. 计算题默认拆成 2–4 个小问，形成“基本量 → 性质/条件判断 → 图形或应用说明”的递进；每个小问只问一件事。
6. 同一大题的小问共享题设，不重复抄条件；后问可以依赖前问结果，但要保证前问有明确可求的中间量。

## 二、题型写法

### 选择题

- 题干 1–2 句，问法直接：性质判断、条件辨析、结果比较、符号/图像识别。
- 选项短而平行，通常 10–35 字；避免四个长段落和“以上都对/都不对”。
- 单选须有一个无争议答案；多选至少两个正确项且答案集合完整。
- 干扰项取自校内常见错误：漏条件、混淆变换域、符号方向反、收敛域判断错、单位/量纲错。
- 不考孤立名词解释；定义题必须落到“适用条件或反例”。

### 判断题

- 一句一个命题，长度约 15–50 字；不用多重否定和“可能、一般”等含糊词。
- 优先考定理前提、公式适用条件、系统性质、概念边界。
- 错误命题要能被一句话指出错因，解析给出正确表述。

### 计算题

- 题设 2–5 句，先给对象和条件，再给已知量、单位和所求；不写无关故事。
- 高频任务动词：求、判断、证明、画出、化简、设计、说明理由。
- 需要画图但当前系统不能插图时，不得写“如图所示”；改为用文字完整描述拓扑、节点连接、波形或表格。
- 中间结果和最终结果都使用标准数学符号；解析给关键代入、判断依据和单位，不写内心推理。
- 数值题必须给出可复核结果；符号题必须说明所用性质或公式的成立条件。

## 三、课程类型适配

| 课程类型 | 客观题侧重 | 综合题侧重 |
|---|---|---|
| 信号、电路、自控 | 性质、条件、稳定性、响应形状 | 变换/系统函数、多小问计算、画图与工程解释 |
| 数电、逻辑 | 逻辑关系、器件功能、条件判断 | 组合/时序分析、设计、化简、波形 |
| 概率、随机过程 | 分布性质、数字特征、条件辨析 | 多步计算、证明、功率谱/相关函数 |
| 工科数学 | 概念与基本运算 | 计算、证明、收敛/存在性判断，多小问递进 |

课程知识必须来自当前证据包；本表只决定题型重心，不提供课程结论。

## 四、语言与公式

1. 使用规范的课程中文；首次出现可附英文缩写，如“线性时不变（LTI）系统”“收敛域（ROC）”。
2. 题干不用“请谈谈”“你觉得”等开放口语；需要论述时限定范围和要点。
3. 所有数学片段使用配对 `$...$`；主公式最多一个，放在 `latex`。上下标、分数、根式、积分、求和、单位必须完整。
4. 表格数据用文字或 LaTeX 数组表达，不依赖图片；同一变量在全题中保持同一含义。
5. 计算题答案与解析的数值、符号、单位必须一致；不把近似值写成精确值，不省略关键条件。

## 五、难度与反模式

**基础题**：单步定义辨析、直接代入、读图/读表判断。
**中等题**：两步以上运算、性质联用、条件比较、需要选择正确公式。
**综合题**：多知识点串联、先判断后计算、设计或应用解释。

禁止：
- 把同一道题换数字或换问法重复出现；
- 用超大计算量冒充难度；
- 出资料未覆盖的定理、公式或专业结论；
- 出只有图才能成立、但题面没有完整图形描述的题；
- 出“以上都不对”、答案不唯一、单位缺失或条件不足的题；
- 把样卷原题、原选项、原解析改写后冒充新题。

## 六、终审清单

- 题量与题型严格符合用户设置；
- 每道题能独立成立，条件、单位、定义域/收敛域齐全；
- 客观题答案唯一或集合完整，干扰项可判定；
- 计算题有小问梯度，关键步骤可复核，答案解析一致；
- 公式可转 MathML/Word OMML；
- 全卷难度大致符合 25/55/20，且没有重复考点；
- 所有事实与公式均有当前知识区证据，样卷只影响风格，不充当证据。
