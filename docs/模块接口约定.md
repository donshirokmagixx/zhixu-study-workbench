# 模块接口约定（v3.1 实现用）

> 本文件约束各 `.py` 模块之间的函数签名与返回结构。实现必须严格一致；`app.py` 的路由只按本文件调用。
> 所有错误使用 `AppError` 子类（见 llm.py）：`code` + `message`，由 app.py 统一转成 `{"error":{"code","message"}}`。
> 所有时间使用 `db.now()`；所有 ID 使用 `db.new_id()`；数据库只通过 `db.q/q1/x/xmany` 访问。

## mindmap.py（backend-office 实现）

```python
def generate(zone_id: str, document_ids: list[str], title: str, mode: str) -> dict
    # mode ∈ {"structure","concept"}；写入 mindmaps + mindmap_nodes
    # 返回 {"mindmap_id","mode","status","truncated","nodes":[node]}；node 见下
    # M2 证据不足 → raise AppError("insufficient_evidence","当前资料不足以生成导图。")（不建记录）
def list_maps(zone_id: str) -> list[dict]       # [{"id","zone_id","title","mode","updated_at","node_count"}]
def get_map(mindmap_id: str) -> dict            # {"id","zone_id","title","mode","updated_at","nodes":[node]}
def save_nodes(mindmap_id: str, nodes: list[dict]) -> dict   # {"ok":True,"updated_at"}
def regenerate(mindmap_id: str) -> dict         # {"mindmap_id","mode","nodes","kept_user_nodes","removed_nodes"}
```

node 结构（API 输出）：`{"id","node_key","parent_key","title","note","source_document_id","source_chunk_ids":[str],"origin","unverified"(0/1)}`。
`save_nodes` 输入允许不含 `id`；`origin` 由程序强制：编辑过的节点置 `"user"`，未改动的保留原值。
