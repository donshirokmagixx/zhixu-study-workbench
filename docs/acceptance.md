# 手动验收清单（对应规格第 19 节）

> 前提：`start.bat` 已启动，浏览器打开 <http://127.0.0.1:8788>；设置页已配置模型并测试连通。
> 每项记录「通过 / 失败 / 未验证」及证据（截图、日志、文件名）。

## A. 数据真实性

| 编号 | 操作 | 期望 |
|---|---|---|
| D1 | 清空 `data/` 后重启，打开首页 | 知识区/资料/会话/消息/导图/试卷/论文/用量全为空；无任何示例内容 |
| D2 | 新建 1 个知识区并上传 1 份资料 | 资料数=1，片段数=真实解析数；其他模块仍为空 |
| D3 | 不点任何生成按钮 | 界面不出现导图/试卷/论文方案 |
| D4 | 清空模型配置后提问；再断网提问 | 显示"未配置模型 API…"或真实网络错误；无假回答、无假引用 |
| D5 | 全仓库搜索 `DEMO_QA`、`示例资料` | 无写死的示例资料/题库/问答/任务/统计 |
