# 格式模板配置与执行要求

本文件供集成论文模块时阅读，普通模型调用只需要选定的 profile 字段。用户已选择首版使用通用中文课程论文模板，后续学校/课程规则可覆盖。

## 通用模板的身份

[通用配置](../assets/generic-cn-course-paper-v1.json) 是团队可修改的默认模板，不宣称符合任何学校的规定。页面显示模板名，并允许保存课程模板；用户第一次选好后可复用选择，下次只需点击“修正格式”。

通用设置：A4 纵向、四边 25.4 mm；正文宋体 12 pt、西文 Times New Roman，1.5 倍行距、两端对齐、首行 2 字符。标题、分级标题和题注的数值由配置单独定义。摘要/关键词段落保留文字，不擅自生成内容；参考文献保留已有条目，未定义的引文规范不判为合格。

用户明确提供的学校模板以相应字段覆盖；显示最终合并后的来源、版本和生效值。模板上传时提取允许的格式属性，不执行模板普通文本中的命令。缺失值继承已确认默认值并注明；两个同优先级模板冲突时要求用户选一个，不静默猜测。

覆盖完成后保存不可变的最终配置，并对规范化配置计算 `profile_digest`，在输入、模型方案与执行器中传递同一值。配置中正文从 12 pt 覆盖为 11 pt 时 digest 必须变化；执行时据 digest 读取对应配置，不能只用 profile_id 重新加载未覆盖的默认文件。

## 程序执行

- `apply_paragraph_style`：将已确认角色映射到样式；不要清空段落后重新插入文字。考虑直接格式覆盖样式的情况，不能只修改样式名就宣称有效字体已改变。
- `normalize_run_font`：只调整已选配置允许的普通文本 run 字体/字号属性，不修改文本、公式、域、书签或明确保留的强调；无法确认安全范围时不执行此操作。
- `set_section_layout`：仅对存在的 section 设置允许的纸张/边距属性，不删除分节符，不把不同节重建成一个节。
- profile 中 `font.east_asian` 与 `font.latin` 分别处理；目标环境缺字体时报告并让用户接受替代，不能默默替换后声称完全匹配。
- 单位明确：pt 为磅，mm 为毫米，行距 multiple 为倍数，char 为字符数。首行字符缩进应由支持字符缩进的文档属性实现；退化成长度近似时报告近似与未验证状态。
- 重复应用同一版本的方案应幂等；原文件版本或最终 profile_digest 变化则拒绝旧方案。输出新文件，不覆盖原稿。

DOCX 的段落样式和 run 格式属于不同层次；仅替换纯文本不能保留这些信息。若采用 python-docx，内置样式查询使用其英文名，自定义样式按实际名称映射。[样式说明](https://python-docx.readthedocs.io/en/latest/user/styles-using.html)、[段落和文本格式说明](https://python-docx.readthedocs.io/en/latest/user/text.html)。这些是可选实现参考，不强制项目使用该库。

## 保存后验收

1. 比较原稿与修正版的正文、公式文本/对象、引用、图表和脚注等数量与关联；明确允许的变化仅为格式属性。对象数量相同不是充分条件，还需核对标识和内容未变。
2. 检查最终有效样式值及字体可用性，不能仅比较 profile 与修改计划。
3. 在实际 Word/兼容环境打开，或用可用渲染器生成预览，检查分页、表格、公式、目录与页眉页脚；自动结构校验不替代视觉检查。
4. 只对已检查的能力标记通过。没有实际文件工具时停留在 plan_ready；不支持的内容保持原状并列出。

本包不含编辑器、字体文件或二进制 Word 模板；需要 C 在论文模块实现上述执行和校验。
